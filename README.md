# Paul Bryant

I write infrastructure automation examples in Python, PowerShell, Ansible, and NCLI. The repositories below cover VMware, Nutanix, and Microsoft platforms. Each repository states its intended product versions and the checks completed so far.

## Repositories

- [VMware automation](https://github.com/vmpebryant01/vmware): vSphere, NSX, and Site Recovery Manager examples. The original scripts were posted in 2025 and target the pre-VCF 9 product generation. Start with the [workflow notes](https://github.com/vmpebryant01/vmware/blob/main/docs/workflows.md) and [script status](https://github.com/vmpebryant01/vmware/blob/main/docs/script_status.md).
- [Nutanix AHV automation](https://github.com/vmpebryant01/nutanix): Prism Central, Prism Element, and AHV examples in Python, Ansible, and NCLI. Check the README before using a workflow.
- [Microsoft infrastructure reports](https://github.com/vmpebryant01/microsoft): read-only Azure Cloud, Azure Local, and SDN reports in PowerShell and Python. The [compatibility index](https://github.com/vmpebryant01/microsoft/blob/main/COMPATIBILITY.md) lists sources and validation limits.

I no longer have a lab for live validation. Local tests and documented API references do not establish that a script works on a particular deployment. All three repositories are all rights reserved.
