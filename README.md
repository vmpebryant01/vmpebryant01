# Paul Bryant

Author: Paul Bryant

I work on infrastructure automation for VMware and Nutanix environments, using Python, PowerShell, Ansible, and NCLI. These repositories collect examples, safety improvements, and notes about the product versions they were written for.

## Repositories

- [VMware automation](https://github.com/vmpebryant01/vmware): vSphere, NSX, and Site Recovery Manager examples. The original scripts were posted in 2025 and target the pre-VCF 9 product generation. Start with the [workflow notes](https://github.com/vmpebryant01/vmware/blob/main/docs/workflows.md) and [script status](https://github.com/vmpebryant01/vmware/blob/main/docs/script_status.md).
- [Nutanix AHV automation](https://github.com/vmpebryant01/nutanix): Prism Central, Prism Element, and AHV examples in Python, Ansible, and NCLI. Start with the [workflow notes](https://github.com/vmpebryant01/nutanix/blob/main/docs/workflows.md) and [script status](https://github.com/vmpebryant01/nutanix/blob/main/docs/script_status.md).

The examples have local checks but have not been validated against a live environment here. Each repository documents its current limits and reuse terms. Both are all rights reserved.
